# Plans

Plans are optional: write one only for an epic that needs more design than its issue body holds.
Write it with `ce-plan` and link it from the epic. It holds architecture and contracts, never the step list; the issues are the queue.
Durable reasoning ends up in `docs/engineering-notes.md` and `docs/decisions.md`.
The three plans that built v1 and the old handoff file are in git history at commit 6d995f3: https://github.com/mjohnson139/words-and-waffles/tree/6d995f3/docs/plans and https://github.com/mjohnson139/words-and-waffles/blob/6d995f3/docs/handoff.md
